IMPORTANT
The iPhone app is the dashboard. The scanner must run on a server/cloud/VPS.
iOS does not reliably allow a Python scanner to stay alive 24/7 in the background.

LOCAL TEST
1) pip install -r requirements.txt
2) Set:
   TELEGRAM_BOT_TOKEN
   TELEGRAM_CHAT_ID
3) python raza_iphone_app.py
4) Open http://127.0.0.1:5000

INSTALL ON IPHONE
1) Open the hosted HTTPS link in Safari.
2) Tap Share.
3) Tap Add to Home Screen.
4) Tap Add.
5) RAZA Signal appears as an app icon.

FREE HOSTING
A free cloud tier can be used when available, but free providers may sleep or impose usage limits.
For reliable 24/7 scanning, an always-on server is required.

SECURITY
Never publish your Telegram bot token in the source code.
Use environment variables.
